# sprint7-final-project

#  Analisis de datos de ConnectaTel 2024

Este repositorio contiene el análisis realizado durante el Sprint 7 del caso ConnectaTel.

El proyecto `everpeak_retail` incluye registros de 4,000 clientes y 40,000 registros del comportamiento de estos clientes de una empresa de telecomunicaciones en Latinoamérica, ConnectaTel.

## 📂 Contenido del repositorio

- plans.csv → información de los planes actuales (precio, minutos incluidos, GB incluidos, costo por extra)
- users.csv → información de los clientes (edad, ciudad, fecha de registro, plan, churn)
- usage.csv → detalle del uso real de los servicios (llamadas y mensajes)

## 🧠 Objetivo del análisis

- Identificar problemas de calidad de datos
- Construir un pipeline de limpieza reproducible
- Analizar comportamientos, distribuciones y outliers
- Generar insights para el equipo de Estrategia e Integración de ConnectaTel.
